# 运行说明

## 1. 解压与目录

将 `02-完整程序源码/完整程序源码.zip` 解压到任意无中文、无空格的目录。以下命令均以解压后的项目根目录为当前目录，不依赖原作者电脑的盘符。

项目包含：

- `risk-warning-platform`：Spring Boot 后端
- `web-admin`：Web 管理端
- `miniprogram`：微信小程序端
- `sql`：数据库初始化与演示数据脚本

## 2. 环境要求

- JDK 21
- Maven Wrapper（源码已提供 `mvnw.cmd`）
- MySQL 8.x
- Node.js 16.x 或更高版本
- 微信开发者工具（仅运行小程序时需要）

## 3. 初始化数据库

先执行 `risk-warning-platform/sql/init.sql`，再按需执行以下补充脚本：

```text
risk-warning-platform/sql/datasource_config.sql
risk-warning-platform/sql/add_declared_value_and_seed.sql
risk-warning-platform/sql/seed_policy_demo.sql
risk-warning-platform/sql/seed_multi_language_demo.sql
```

这些数据是项目演示样例，页面和接口会标记为 `DEMO`，不代表真实政务数据或真实企业征信结论。

## 4. 启动后端

在 `risk-warning-platform` 目录执行：

```powershell
.\mvnw.cmd spring-boot:run
```

如果项目目录包含中文路径，Maven Wrapper 可能出现启动类路径乱码；此时先执行 `.\mvnw.cmd -q package -DskipTests`，再使用下面命令启动：

```powershell
java -jar target\risk-warning-platform-1.0.0.jar
```

后端地址：`http://127.0.0.1:8080`。

默认演示账号：`admin`，密码：`123456`。正式部署时请通过 `APP_AUTH_ADMIN_HASH` 配置 BCrypt 密码，不要使用演示密码。

## 5. 启动 Web 管理端

在 `web-admin` 目录执行：

```powershell
npm install
npm run serve
```

访问：`http://127.0.0.1:3000`。

## 6. 启动微信小程序

用微信开发者工具导入 `miniprogram` 目录，并将后端地址配置为：

```text
http://127.0.0.1:8080/api
```

如果使用真机调试，在微信开发者工具“本地存储”新增：

```text
键：apiBaseURL
值：http://本机局域网IP:8080/api
```

真机和电脑必须处于同一局域网；正式上线时需替换为备案 HTTPS 域名并配置小程序合法域名。

## 7. Docker 启动

在 `risk-warning-platform` 目录执行：

```powershell
docker compose up --build
```

可通过环境变量覆盖数据库配置，例如：

```powershell
$env:DB_PASSWORD='自定义数据库密码'
$env:APP_AUTH_ADMIN_HASH='自定义BCrypt密码哈希'
docker compose up --build
```

## 8. 快速验收

后端和 Web 启动后，在 `04-测试程序` 目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\competition-preflight.ps1
```

验收脚本会检查登录、企业搜索、风险评分、欺诈预警、多语言、官方数据溯源、跨境图谱和跨境档案等核心功能。
