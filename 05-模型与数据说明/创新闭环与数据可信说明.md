# 创新闭环与数据可信说明

## 一、项目主线

本项目的核心不是单纯展示企业信息，而是面向广西—东盟跨境贸易场景，形成“发现风险—解释风险—给出建议—生成报告—复核状态”的企业风险闭环。

```text
企业/统一信用代码
        ↓
目标东盟国家与贸易场景
        ↓
企业基础、经营合规、口岸通关、贸易活跃、国别政策数据
        ↓
默认评分卡或国别差异化评分卡
        ↓
风险分、风险标签、证据来源
        ↓
合规整改建议与合规报告
        ↓
待整改 → 整改中 → 已复核（演示流程）
```

## 二、数据可信分层

| 数据层 | 当前用途 | 页面标识 | 使用边界 |
|---|---|---|---|
| 官方公开数据目录、公开网页和公开统计快照 | 说明数据来源、国家覆盖和来源链路 | `official_public` / 来源名称 / 抓取时间 | 需遵守来源许可，不能替代授权业务数据 |
| 项目演示样例数据 | 支撑本地演示和模型流程复现 | `DEMO` / 项目演示样例 | 不代表真实企业信用结论 |
| 模型计算结果 | 风险提示、国别评分和整改建议 | 模型版本、计算时间、脱敏标识 | 不作为行政处罚、授信或退税认定的唯一依据 |

企业名称、政策标题与正文、司法案例正文保留原始数据语言；外语展示仅对界面标签和已登记的名称映射进行辅助翻译，避免把机器翻译冒充正式原文。

## 三、字段到模型的映射

| 评分维度 | 主要输入字段 | 计算含义 |
|---|---|---|
| 基础资质 | 注册资本、成立年限、对外贸易备案、跨境电商备案 | 衡量企业基础经营和外贸资质 |
| 经营合规 | 经营异常、行政处罚、失信状态、近期异常 | 识别企业经营合规风险 |
| 口岸通关 | 违规报关次数、查验异常率、通关时长偏差 | 识别口岸申报和履约风险 |
| 贸易活跃 | 近12个月申报次数、商品品类数、连续活跃月份 | 判断贸易行为的持续性和完整性 |
| 综合调整 | 行业类别 | 对高风险或重点行业进行场景化修正 |

## 四、可复现案例：东兴市众达贸易有限公司

当前演示数据库中，该企业默认模型返回：基础资质 65、经营合规 30、口岸通关 30、贸易活跃 60、综合调整 80，命中 3 项风险扣分。

```text
30 + 65×0.20 + 30×0.30 + 30×0.25 + 60×0.15 + 80×0.10 - 3×5
= 61.50
```

因此默认模型结果为 `61.50 / 中风险`。切换越南模型后，接口实际返回 `47.25 / 中风险`，原因是越南模型调整了维度权重，并按演示规则叠加口岸查验不合格次数扣分。该结果可通过接口和页面中的模型版本、评分维度及风险证据复核。

## 五、闭环输出

评分结果会同步生成：

1. 风险证据：说明命中的风险因子、来源类型和后续核验方式；
2. 整改建议：按维度和优先级给出报关单证、经营合规或目标国资质复核建议；
3. 合规报告：汇总企业信息、评分、欺诈预测、国别提示和合规检查项；
4. 复核状态：当前为演示流程的“待整改”，不宣称已接入真实监管处置系统。

## 六、限制与后续验证

当前数据用于参赛演示和流程复现，尚未形成可用于生产部署的真实标注样本集。因此本项目不宣称模型准确率、误报率或真实监管效果。后续接入授权数据后，应按企业和事件时间切分训练/验证样本，使用准确率、召回率、F1、ROC-AUC和误报率进行独立评估，并由业务部门复核风险标签。
